; movement_speed_probe.txt
; Measures exact player movement per frame by injecting disc direction into $0167.
;
; How it works:
;   $0167 = EXEC disc shadow register (bits 6:0 = direction 0-8, bit 7 = new-data flag).
;   L_5F43 ($5F43) reads from $0165-$0167 and returns R0 = $0167 & $7F (the disc direction).
;   Breaking at $5F43 and poking $0167 before each frame gives clean single-frame deltas.
;
; Direction encoding (EXEC standard): 0=none 1=N 2=NE 3=E 4=SE 5=S 6=SW 7=W 8=NW
;
; After running, grep the output for "SNAP:" lines and compute:
;   MOVE_SPEED_Y = |Y_with_N - Y_idle| = pixels moved north per frame
;   MOVE_SPEED_X = |X_with_E - X_idle| = pixels moved east per frame
